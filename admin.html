How It Works

1. Type your message and pick a color.
2. Toggle it On and hit Save Banner.
3. The banner saves to this browser. To show it on the live site, a small script on each page reads it — this works best if you always manage the site from the same browser/device.
4. Toggle Off anytime to hide it without losing your message.
